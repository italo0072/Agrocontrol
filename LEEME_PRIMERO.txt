Conserva .env.local y tu historial Git.

Para probar la demo:
1. Instala Node.js 24 LTS desde https://nodejs.org
2. Extrae el ZIP y abre agrocontrol en VS Code.
3. En la carpeta donde está package.json:

   npm ci
   Copy-Item .env.example .env.local
   npm run dev

4. Abre http://localhost:3000 y pulsa Abrir demostración.

Para datos reales, completa .env.local según la guía de Supabase.
